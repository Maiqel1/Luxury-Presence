# Marci Metzger — Homepage Revamp

Single-page revamp of the marcimetzger.com homepage.

Built with Next.js, React, TypeScript, Tailwind CSS, Motion and Aceternity UI.

## Scripts

```bash
npm install
npm run dev            # development server
npm run build          # production build
npm start              # serve the production build
npm test               # unit tests
npm run lint           # lint
npm run fetch-assets   # download and prepare images from the original site
npm run build-map      # regenerate the dotted map used in the "Record" section
```
